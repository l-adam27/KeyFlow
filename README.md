## KeyFlow  —  custumizable keypad for your favorite shortcuts

Built for faster workflow and maximum productivity

---

Main:

Keyflow is a small macropad, that I designed to give the user the fastest ways to control his enviroment

---

Standart layout:

> Important:
> The key mapping listed below is the fabric standart, a future software will be implemented soon

Key Mapping:

KEY 1 - SCREENSHOT        
KEY 2 - MEDIA CONTROL        
KEY 3 - LOCK SCREEN        
KEY 4 - FOCUS MODE        
KEY 5 - CLEAN DESKTOP        
KEY 6 - MICROFONE MUTE        

----

Rotary Encoder (Knob):

- Rotate: Volume + / Volume -
- Press: Audio mute / unmute
